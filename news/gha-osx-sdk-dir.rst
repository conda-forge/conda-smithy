**Added:**

* Setting ``OSX_SDK_DIR`` in ``conda_build_config.yaml`` (e.g. zipped with ``github_actions_labels``) now sets it as an environment variable for that variant's macOS job in the GitHub Actions workflow, instead of in the ``.ci_support`` file, so that conda-forge-ci-setup can take a macOS SDK it does not download from a specific Xcode on the runner.
